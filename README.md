# ErdetspillShaderMod

Erdetspill shader mod

## Instructions

### Modloader

Download the Erdetspill Modloader by Goglesser: https://github.com/Goglesser/Erdetmodloader/releases 

Move the files in the zip-file to your erdetspill steamapp folder
(usually located at "\Program Files (x86)\Steam\steamapps\common\erdetspill")

Install by running the INSTALL_MODLOADER.bat file

### Shader mod

Download the ErdetShader mod

Place the zip file (don't un-zip) in the "mods" folder

Toggle the Shader mod in the Shader settings the mod added to Erdetspill (on by default)
